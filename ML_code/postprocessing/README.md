# 5C post-processing and candidate selection

This module processes the complete prediction table generated by `ML_code/predict_5c.py`.

## Workflow

1. Read the full prediction CSV in chunks.
2. Identify the prediction score (normally `pred_retention_5C`) and full formulation sequence (`seqA`).
3. Assign each row to a salt system using the `salt1` and `salt2` columns.
4. Normalize salt labels for grouping. In this project, `LiPO2F2` and `LiDFP` are treated as the same auxiliary salt and both are labelled `LiDFP`.
5. Within each salt system, compare the complete sequence strings exactly. If a sequence occurs more than once, retain the row with the highest prediction score.
6. Rank the unique sequences independently in each salt system and export at most Top-N rows per group.

The current project design contains ten salt systems: three single-main-salt systems, six main-salt/auxiliary-salt combinations, and one LiPF6/LiFSI dual-main-salt system.

## Requirements

```bash
python -m pip install pandas
```

## Run from the repository root

```bash
python ML_code/postprocessing/select_topn_by_salt.py \
  --input /path/to/all_pred_place_5C.csv \
  --output /path/to/top_candidates_by_salt \
  --top-n 100000 \
  --chunk-size 200000 \
  --condition-tag 5C
```

Optional column overrides: `--score-col`, `--seq-col`, `--salt1-col`, and `--salt2-col`.

## Deduplication details

Deduplication uses exact string equality of `seqA` after trimming leading and trailing whitespace. This script does not reorder component slots, canonicalize molecular SMILES, or round composition values. The two salt names are canonicalized only for salt-system grouping. For a repeated sequence within one salt system, the row with the highest prediction score is retained.

The input is processed in chunks. For each salt group, the retained Top-N unique rows from previous chunks are merged with the current chunk, deduplicated and ranked again. Rows below Top-N in a previous chunk cannot enter the final Top-N unless a higher-scoring duplicate is encountered; the repeated sequence is handled by the subsequent merge and deduplication.

## Outputs

- One ranked CSV per salt system.
- A summary CSV with the number of exported unique sequences and score statistics for each salt system.
- A JSON run record with input settings, row counts, salt aliases and runtime.

The total exported count is the sum of the independently capped salt-system groups. It is not necessarily equal to ten times Top-N.

## Data policy

Only code and documentation are stored here. Do not commit `place.csv`, full prediction tables, curated literature data, experimental records, private workbooks or private API credentials.
